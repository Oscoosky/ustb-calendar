# 北科大 2026–2027 学年校历标注

一个**离线网页应用**，按北京科技大学 2026–2027 学年校历整理。支持导入学生课表、按天查看课程、编辑课程，以及标注考试、竞赛和实验。**每次导出一个学期，每学期一张 A4 竖版纸**。

## 在线访问

**https://oscoosky.github.io/ustb-calendar/**

手机、平板、电脑打开浏览器即可使用，无需安装。课表和标注保存在**当前浏览器本地**，不会上传到服务器，也不会自动同步到其他设备；换设备时请用“备份”导出的 JSON 恢复。

也可以下载仓库后双击 `index.html` 离线使用。

> 公开仓库不包含个人课表截图；课表数据只在你的浏览器里。

## 功能

- **按周查看**：秋季、春季各 18 个校历周；第 17–18 周为考试周，自动标红。
- **月份独立成列**：每个学期右侧有月份栏，每周显示当前月份，每月起始行加粗并加绿色标记。
- **导入学生课表**：支持 `.xlsx / .xls`，按星期、节次、周次、地点、教师解析。
- **按天查看课表**：点击任意日期，查看当天课程和已有标注。
- **编辑课表**：课程可单独修改星期、节次、周次、地点、教师、类型；也可以手动添加或删除。
- **点击日期标注**：支持考试、竞赛、实验、其他四类。
- **多日事件**：例如连续五天的实验周，会出现在区间内每一天。
- **补充信息**：可选填时间、地点、备注。
- **编辑 / 删除**：点击日历中的彩色标签即可修改标注。
- **筛选与定位**：按类别筛选、切换学期、回到今天。
- **本地保存**：标注和课表都保存在当前浏览器中，不上传。
- **备份 / 导入**：导出 JSON 备份（含课表），换浏览器或重装后可导入恢复。
- **打印 / 导出 PDF**：
  - 秋季学期一张 A4 竖版
  - 春季学期一张 A4 竖版
  - 每次只导出一个学期；有课的日期会显示「课N」摘要
  - 可选是否打印事件文字、节假日
- **已附空白打印版**：
  - `北科大2026-2027校历-秋季-A4空白.pdf`
  - `北科大2026-2027校历-春季-A4空白.pdf`

## 导入学生课表

1. 点击右上角 **课表**。
2. 在弹窗顶部选择 **秋季** 或 **春季**。
3. 点击 **导入 Excel**，选择学生课表文件。
4. 导入后关闭弹窗，点击任意日期即可查看当天课程。
5. 点击课程右侧的铅笔按钮修改；也可以点 **添加课程** 手动录入。

导入会替换当前学期已有的课表，导入前会二次确认。课表按周次显示：例如「1-8周」只会在第 1–8 周出现。

当前适配的是按星期排列的学生课表；如果 Excel 结构不同，可能需要在「添加课程」里手动修正。

## 打印为 PDF

1. 点击右上角 **打印 / PDF**。
2. 选择要导出的学期（秋季或春季）和是否显示文字/节假日。
3. 点击 **打印 / 另存 PDF**。
4. 在浏览器打印窗口中选择 **另存为 PDF**，建议：
   - 纸张：A4
   - 方向：纵向
   - 边距：无
   - 勾选 **背景图形**（否则考试周底纹和标签颜色会丢失）

## 数据说明

- 标注存储键：`ustb-calendar-2026-2027-v1`
- 课表存储键：`ustb-timetable-2026-2027-v1`
- 数据只在本机浏览器里，**清除浏览器数据、换浏览器或移动文件都可能导致数据丢失**。
- 建议每次集中标注/导入课表后点击 **备份** 导出一份 JSON；备份会同时包含标注和课表。
- 导入 JSON 会**替换**当前标注和课表，导入前会二次确认。

## 校历口径

- 秋季学期：第 1 周从 2026-09-07 起；第 17–18 周为考试周（2027-01-04 至 2027-01-17）。
- 秋季秋假：2026-09-28 至 2026-10-07；日历中 09-28 至 10-04 作为不编号的假期周，第 4 周从 10-05 起。
- 春季学期：第 1 周从 2027-03-01 起；第 17–18 周为考试周（2027-06-28 至 2027-07-11）。
- 春季春假：2027-05-01 至 2027-05-07；日历中 05-03 至 05-09 作为不编号的假期周，第 10 周从 05-10 起。
- 节假日只预置校历中可确认的日期；打印时默认不显示，避免版面拥挤。

- `北科大2026-2027校历-秋季-A4空白.pdf`：秋季学期空白 A4 竖版打印版。
- `北科大2026-2027校历-春季-A4空白.pdf`：春季学期空白 A4 竖版打印版。
- `preview/`：界面、课表和打印效果预览图。
